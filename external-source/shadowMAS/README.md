## What This Source Is

shadowMAS is an authority-boundary evaluation construct and open testbed for multi-agent AI systems. It focuses on authority-bounded interpretation: runtime signals, audit projections, memory candidates, and recommendations should not silently become truth, memory, approval, or decision authority.

## Why It Is Collected

This source may be useful for refining personal-ai-runtime workflows around:

- authority boundary design
- human-governed promotion and review gates
- prompt layering and compiled intake
- machine-first artifacts for agent workflows
- separation between product repositories and external agent runtime state
